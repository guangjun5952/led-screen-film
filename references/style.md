# 默认风格：LED 点阵翻拍（六要素）

| 要素 | 本风格的答案 | 引擎里的实现 |
|---|---|---|
| 介质 | 被摄像机翻拍的 LED 点阵屏 | 640×360 灯珠画布，输出 1920×1080，灯珠间距约 3px |
| 出字 | 逐字打出，新字先亮强调色再退成白色，带斜线块状光标 | `typed()` / `typed_plate()` |
| 标注 | 旁边挂着 "x: 1307 y: 558" 式坐标追踪标签，加一根引线 | `mono()`、`pro(lead=...)` |
| 色彩 | 每个镜头换一个主色；黑底；文字 `#e8ecf0` | 常量 `GREEN CYAN AMBER MAGENTA PINK ORANGE TEXT_WHITE` |
| 转场 | 硬切，切点一帧闪白（粉白带摩尔纹）、偶尔故障切片 | `render_clip(flashes=[(t, 0.07, (1,.92,.95))], glitches=[(t, d, amt)])` |
| 运动 | 快推、甩镜、绕转，带真实拖影 | `Cam` 关键帧 + 子帧快门（自动） |

## 已经调好的参数（来自用户意见，别改回去）
- 辉光：bloom 0.32 / 0.38；高光溢出系数 0.35；全局亮度 `GAIN_SCALE 0.84`。
- 白字不要打满，用 `TEXT_WHITE`，大字一律垫黑底。
- 景深 dof 0.25–0.35；滚动亮带 band 0.03–0.06；颗粒 grain 0.018。

## 花字系统（全片统一五种）
1. **章节卡**：像素字 "STEP 01 / 05" + 猴尊宋体大字 + Instrument Serif 英文副标题。
2. **关键词**：`typed_plate`，黑底垫字，重点字用强调色。
3. **梗字**：`gag()`，粉色色块，弹出时带抖动。全片不超过 5 次。
4. **PRO 注释**：`pro()`，像素字加引线，写给专业观众看的参数和原理。
5. **对话框**：`chat_box()`，模拟发消息，逐字打出后回车。

## 节奏
- 前 5 秒：强画面加钩子文案（数字计时器、穿梭、频闪蒙太奇都可以）。
- 卡词，不卡音乐：关键词出现的那一帧，对齐旁白念到那个字的起点。
